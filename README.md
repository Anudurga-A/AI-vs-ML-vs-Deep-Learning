# AI-vs-ML-vs-Deep-Learning

## Introduction
This project explains the differences between Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL). It provides simple definitions, a comparison table, and real-world examples to understand these concepts clearly.

## Objective
To build a clear understanding of AI, ML, and Deep Learning, their differences, applications, and relationships.

## Concepts Covered
- Artificial Intelligence (AI)
- Machine Learning (ML)
- Deep Learning (DL)
- Comparison of AI, ML, and Deep Learning
- Real-world applications
- Relationship between AI, ML, and Deep Learning

## Comparison
- **AI:** Enables machines to perform tasks that normally require human intelligence.
- **ML:** Enables computers to learn from data and make predictions.
- **Deep Learning:** Uses multi-layered neural networks to learn complex patterns.

## Real-World Examples
- **AI:** Chatbots and virtual assistants
- **ML:** Spam detection and recommendation systems
- **Deep Learning:** Face recognition and speech recognition

## Tools Used
- Python (optional)
- Jupyter Notebook

## Dataset
No dataset is required for this project.

## Conclusion
Artificial Intelligence is the broader field, Machine Learning is a subset of AI, and Deep Learning is a subset of Machine Learning. These technologies are widely used in modern applications to solve real-world problems.
